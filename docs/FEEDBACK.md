# 의견 수집 폼 연결

집사의 의견 수집은 Google Forms를 기본 브라우저로 여는 방식입니다. 별도 서버, 앱 로그인, Google API 키는 필요하지 않습니다. 폼은 운영자의 Google 계정으로 소유하고 응답을 확인합니다.

## 폼 만들기

1. [Google Apps Script](https://script.google.com/home/start)에서 새 프로젝트를 만듭니다.
2. 기본 코드를 지우고 [폼 생성 스크립트](../scripts/create-feedback-form.js)의 내용을 붙여 넣습니다.
3. `createZipsaFeedbackForm` 함수를 실행하고 Google Forms 접근을 허용합니다. 스크립트를 웹 앱으로 배포할 필요는 없습니다.
4. 실행 로그에 표시된 **폼 편집** 주소를 엽니다. 게시 설정의 응답자 범위가 **링크가 있는 모든 사용자**인지 확인합니다. Google Workspace 계정은 조직 정책으로 외부 응답이 제한될 수 있으므로 개인 Google 계정을 권장합니다.
5. **응답용 주소**를 시크릿 창에서 열어 로그인 없이 작성할 수 있는지 확인합니다. 테스트 의견 하나를 제출하고 폼의 **응답** 탭에서 확인합니다.
6. 실행 로그의 JSON을 저장소 루트 [feedback.config.json](../feedback.config.json)에 넣습니다. `__ZIPSA_VERSION__`, `__ZIPSA_OS__` 표시는 그대로 둡니다.
7. 앱을 다시 빌드합니다. 설정의 **의견 보내기**에서 실제 버전과 운영체제가 채워지는지 확인한 뒤 새 버전을 배포합니다.

동일한 Apps Script 프로젝트에서 함수를 다시 실행하면 기존 폼과 설정을 반환합니다. 질문 제목 `앱 버전`, `운영체제`는 스크립트에서 참조하므로 유지하세요. 폼 편집 주소와 Google 계정 인증 정보는 앱 설정에 넣지 않습니다.

## 입력 항목과 설정

| 항목             | 입력                                       |
| ---------------- | ------------------------------------------ |
| 어떤 의견인가요? | 버그 제보 · 기능 제안 · 기타 중 선택, 필수 |
| 의견 내용        | 긴 글, 필수                                |
| 답변받을 이메일  | 선택, 이메일 형식 확인                     |
| 앱 버전          | 앱에서 열 때 자동 입력, 수정 가능          |
| 운영체제         | macOS · Windows 자동 입력, 수정 가능       |

스크립트는 이메일 자동 수집, 1인 1회 제한, 응답 요약 공개를 끕니다. 파일 업로드 항목을 만들지 않습니다. 답변용 이메일을 비워도 제출할 수 있습니다. 응답자는 다른 사람의 의견을 볼 수 없으며, 폼 소유자와 소유자가 추가한 공동작업자만 응답에 접근하도록 공유 설정을 유지하세요. 새 의견 알림은 폼의 **응답 → 더보기 → 새로운 응답에 대한 이메일 알림 받기**에서 켤 수 있습니다.

## 앱에서 보내는 정보

앱은 사용자가 **의견 보내기**를 누를 때만 브라우저를 엽니다. URL에는 앱 버전과 운영체제 이름만 미리 채웁니다. 의견 내용과 이메일은 Google Forms에서 직접 작성하고 제출합니다. 공간·아이템·사진·할 일·백업·로그·데이터 저장 경로는 첨부하지 않습니다. 브라우저가 Google에 접속할 때의 일반적인 연결 정보 처리는 Google 정책을 따릅니다.

폼 연결 주소는 공개 정보이며 앱 빌드에 포함됩니다. 설정이 비어 있거나 유효하지 않으면 앱에 의견 보내기 항목을 표시하지 않습니다. URL은 HTTPS의 Google Forms 응답 페이지만 허용하며, 설정의 다른 미리 채운 값과 추적 파라미터는 제거합니다. 폼을 바꾸면 앱을 다시 빌드해 배포해야 합니다.

수동으로 폼을 만들 경우 **미리 채우기** 기능으로 앱 버전에 `__ZIPSA_VERSION__`, 운영체제에 `__ZIPSA_OS__`를 넣고 생성한 링크를 `prefilledUrl`에 설정하면 됩니다.

참고: [Google Forms 공유·미리 채운 링크](https://support.google.com/docs/answer/2839588?hl=ko), [Google Apps Script Forms API](https://developers.google.com/apps-script/reference/forms).
